SAÉ - Développement d’une application Web de gestion de Drive

Projet universitaire · RT3 informatique · Application web complète

Projet de groupe RT3 : conception, développement et déploiement d’une application web de gestion de Drive, intégrant back‑end, base de données et interface utilisateur.

En bref :

Solution complète pour gérer produits, clients et commandes, avec import de données et génération automatique de fiches.

Objectifs

  • Mettre en place un CRUD complet pour produits, clients et commandes
  • Importer catalogue produit depuis un fichier
  • Générer automatiquement une fiche de commande et calculer le total
  • Déployer l’application sur une VM Linux

Fonctionnement

Interface web pour gérer catalogue et clients, créer des commandes multi‑produits, et générer des fiches récapitulatives exportables.

Base de données

Schéma relationnel simple : tables pour catégories, produits, clients, commandes et association produits‑commandes (quantités, prix).

Technologies et déploiement

  • Front : HTML / CSS / JavaScript
  • Back : PHP + MySQL (MariaDB)
  • Serveur : VM Linux (Apache)
  • Outils : Git, GitHub, documentation et gestion de projet

Architecture technique

Le projet suit une architecture client / serveur.

  • Le navigateur communique avec le serveur web
  • Le serveur traite les requêtes PHP
  • Les données sont stockées dans une base SQL
  • Les résultats sont renvoyés dynamiquement à l’utilisateur

L’ensemble des services est déployé sur une machine virtuelle Linux configurée manuellement.

Travail collaboratif

Le projet étant réalisé en groupe, une répartition des tâches a été mise en place grâce à un diagramme de Gantt. Chaque membre du groupe participe au développement, à la documentation, aux tests, au déploiement et à la présentation finale.

Le code source est centralisé sur un dépôt GitHub afin de faciliter le travail collaboratif et le suivi des modifications.

Enjeux et solutions

  • Sécurisation des formulaires et validation côté serveur
  • Conception des relations SQL et intégrité des données
  • Automatisation de l’import produit et tests de charge
  • Déploiement et configuration de la VM Linux

Résultat attendu

Le résultat final est une application web fonctionnelle permettant la gestion complète d’un Drive, l’administration des produits et clients, la création de commandes, la manipulation de données via une interface simple, ainsi que le déploiement autonome sur serveur Linux.

Conclusion

Projet complet appliquant des compétences de développement web, administration et gestion de données ; expérience proche d’un cas réel de production.
