SAÉ - Développement d’une application Web de gestion de Drive

Projet universitaire · RT3 informatique · Application web complète

Dans le cadre de cette SAÉ liée à la compétence RT3 informatique, notre projet consiste à concevoir et déployer une application web permettant la gestion complète d’un service de Drive. L’objectif est de développer une solution permettant de stocker, consulter, modifier et manipuler des données à travers une interface web conviviale accessible depuis un navigateur.

Présentation du projet :

Le projet doit être réalisé en groupe de trois étudiants et s’appuie sur plusieurs compétences étudiées durant la formation, notamment la programmation, les technologies web, les bases de données, les systèmes Linux et le travail collaboratif.

Objectifs du projet

Le projet a pour objectif principal de développer une plateforme web de gestion de commandes de Drive permettant plusieurs opérations essentielles.

  • Gérer les produits
  • Gérer les catégories
  • Gérer les clients
  • Gérer les commandes
  • Ajouter des produits via un fichier
  • Générer une fiche de commande avec calcul automatique du coût total

L’application doit également implémenter un système CRUD complet pour chaque type de données.

Fonctionnement de l’application

Le site web permet aux utilisateurs d’ajouter de nouveaux clients, de consulter les produits disponibles, de créer des commandes, d’ajouter des produits à une commande avec quantité et de générer automatiquement une fiche récapitulative.

Chaque commande est associée à un client et contient plusieurs produits avec une quantité spécifique.

Base de données

Le projet repose sur une base de données relationnelle contenant plusieurs tables :

  • Catégories : nom et description des catégories
  • Produits : nom, prix, marque, photo, date de péremption
  • Clients : informations des clients
  • Commandes : informations des commandes
  • Produits_Commandes : association produits / commandes avec quantité

Les relations entre les tables permettent une gestion cohérente des données et facilitent les requêtes SQL.

Technologies utilisées

Développement Web

  • HTML
  • CSS
  • JavaScript
  • PHP

Base de données

  • MySQL / MariaDB

Hébergement et système

  • Machine virtuelle Linux
  • Apache2
  • PHPMyAdmin
  • Serveur SQL

Outils collaboratifs

  • Git
  • GitHub
  • Diagramme de Gantt
  • Documentation collaborative

Architecture technique

Le projet suit une architecture client / serveur.

  • Le navigateur communique avec le serveur web
  • Le serveur traite les requêtes PHP
  • Les données sont stockées dans une base SQL
  • Les résultats sont renvoyés dynamiquement à l’utilisateur

L’ensemble des services est déployé sur une machine virtuelle Linux configurée manuellement.

Travail collaboratif

Le projet étant réalisé en groupe, une répartition des tâches a été mise en place grâce à un diagramme de Gantt. Chaque membre du groupe participe au développement, à la documentation, aux tests, au déploiement et à la présentation finale.

Le code source est centralisé sur un dépôt GitHub afin de faciliter le travail collaboratif et le suivi des modifications.

Difficultés rencontrées

  • Gestion des relations entre les tables SQL
  • Sécurisation des formulaires web
  • Import de fichiers produits
  • Configuration du serveur Linux
  • Déploiement des services web
  • Gestion collaborative du code avec Git

Résultat attendu

Le résultat final est une application web fonctionnelle permettant la gestion complète d’un Drive, l’administration des produits et clients, la création de commandes, la manipulation de données via une interface simple, ainsi que le déploiement autonome sur serveur Linux.

Conclusion

Cette SAÉ permet de mettre en pratique plusieurs compétences importantes du domaine informatique : développement web, programmation, administration Linux, gestion de bases de données, architecture client / serveur, gestion de projet et travail collaboratif.

Ce projet se rapproche d’une application professionnelle réelle et constitue une première expérience complète de développement et de déploiement d’un service web.
