SAÉ 1.05 — Outil de reporting des gros fichiers

Semestre 1 · Python · Analyse de l’espace disque

Dans le cadre de la SAÉ 1.05, nous avons développé un outil de reporting permettant d’analyser l’espace disque d’un ordinateur afin de localiser rapidement les fichiers les plus volumineux présents dans une arborescence donnée.

Présentation du projet :

Ce projet répond à une problématique fréquente en administration système : le manque d’espace de stockage sur les postes utilisateurs pouvant empêcher certaines mises à jour ou l’installation de nouveaux logiciels.

Présentation du projet

L’objectif principal du projet est de faciliter la maintenance d’un parc informatique en automatisant la recherche des fichiers occupant le plus d’espace disque. L’application est compatible Windows, MacOS et Linux.

Fonctionnement général

  1. Un premier script Python permet à l’utilisateur de sélectionner un répertoire de base grâce à une interface graphique PyQt5.
  2. Un second script analyse récursivement tous les fichiers contenus dans ce répertoire et ses sous-dossiers.
  3. Les fichiers sont triés par taille décroissante afin de conserver uniquement les plus volumineux.
  4. Les résultats sont enregistrés dans un fichier JSON.
  5. Un troisième script génère une interface graphique affichant les données sous forme de camembert accompagné de légendes interactives.
  6. L’utilisateur peut sélectionner certains fichiers grâce à des cases à cocher afin de générer automatiquement un script PowerShell de suppression.

Technologies utilisées

  • PyQt5 pour l’interface graphique
  • PyQtChart pour la création du graphique circulaire
  • pathlib pour la gestion multiplateforme des chemins de fichiers
  • json pour le stockage des données
  • PowerShell pour l’automatisation et la suppression des fichiers

Aspects techniques

Chaque fichier analysé est stocké sous la forme :

[chemin_complet_du_fichier, taille_en_octets]

Les fichiers sont ensuite triés grâce à la fonction sorted() associée à une fonction lambda. Le programme conserve uniquement les 100 plus gros fichiers dépassant une taille minimale définie.

Le projet a également nécessité une attention particulière concernant la compatibilité entre les systèmes d’exploitation, notamment pour la gestion des chemins Windows utilisant les antislashs (\\).

Résultat final

Le résultat obtenu est une application graphique capable de visualiser rapidement les fichiers occupant le plus d’espace disque. Le camembert permet d’identifier facilement les fichiers dominants tandis que les légendes détaillent leur emplacement et leur taille.

L’utilisateur peut ensuite générer un script PowerShell sécurisé permettant de supprimer uniquement les fichiers sélectionnés après double confirmation.

Conclusion

Cette SAÉ nous a permis de mettre en pratique la programmation Python, la programmation orientée objet, la manipulation de fichiers, la création d’interfaces graphiques, la gestion de données JSON, ainsi que l’automatisation système avec PowerShell.

Ce projet se rapproche d’un véritable outil utilisé en administration système et montre comment Python peut être utilisé pour créer des applications complètes mêlant analyse de données, visualisation et automatisation.

Compétences mobilisées

  • Programmation Python
  • Programmation orientée objet
  • Manipulation de fichiers
  • Création d’interfaces graphiques
  • Gestion de données JSON
  • Automatisation système avec PowerShell
